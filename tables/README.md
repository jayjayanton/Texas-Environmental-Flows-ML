# Tables and analysis outputs

This folder contains tabular results extracted from the original notebooks or generated by the command-line scripts.

- [ecoregion_inflection_indices.csv](ecoregion_inflection_indices.csv): candidate curvature-change indices printed by the original `Regression_Tree_Runs.ipynb` for the 10 ecoregions. The numbers are **array indices**, not confirmed ecological thresholds.
- The current `scripts/metric_depth_sweep.py` writes `outputs/metric_runs.csv`.
- The current `scripts/analyze_depth_runs.py` writes `outputs/analysis/mean_r2_by_depth.csv` and `candidate_inflections.csv`.

Original input data and the full historical `Metric_Runs_V2.xlsx` are not included.
